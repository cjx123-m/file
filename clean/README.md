# 共享单车数据清洗（题 5）

数据：`题5_共享单车骑行_202401.csv`（238,834 行、13 列，2024 年 1 月华盛顿特区 Capital Bikeshare 骑行记录）。

按五步清洗管线组织，每一步一个分支，分支名与清洗步骤一一对应：

| 步骤 | 分支 | 内容 |
| --- | --- | --- |
| 1 去重 | `01-去重` | 按业务主键 `ride_id` 去重 |
| 2 归一类别 | `02-归一类别` | 站点名去 NBSP/空白；类别统一大小写与同义词 |
| 3 转数值 | `03-转数值` | 时间戳转 datetime、经纬度转 float，派生 `duration_sec` |
| 4 补缺删缺 | `04-补缺删缺` | 关键字段缺失删行，站点名缺失填“未知站点” |
| 5 标记异常 | `05-标记异常` | 先标记（时长/坐标/月份），再剔除硬异常 |

每个分支都基于上一步的分支创建，按顺序合并即可得到完整管线。

## 运行

```bash
python -m clean.clean
```

输出写入 `output/`（结果文件已提交到仓库）：

- `rides_marked.csv`：全部记录 + 异常标记列
- `rides_clean.csv`：剔除硬异常后的分析表
- `rides_clean_sample1000.csv`：前 1000 行样本，便于快速查看
- `cleaning_report.txt`：行数与分组统计

## 关键顺序

先转数值、再判异常：`duration_sec` 与经纬度完成类型转换后，异常判据才能用统一的数值比较。
